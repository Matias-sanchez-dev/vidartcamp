# Carpeta de Imágenes - VidartCamp

Esta carpeta contiene las imágenes estáticas del sitio.

## Imágenes requeridas:

### Logo
- **Nombre del archivo**: `logo.png` o `logo.svg`
- **Tamaño recomendado**: 
  - Ancho: 200-400px
  - Alto: 100-200px (o proporcional)
- **Formato**: PNG con fondo transparente (preferido) o SVG
- **Uso**: Aparecerá en la navegación de todas las páginas

### Banner/Fondo
- **Nombre del archivo**: `banner.jpg` o `banner.png`
- **Tamaño recomendado**: 
  - Ancho: 1920px (mínimo 1200px)
  - Alto: 600-800px
- **Formato**: JPG o PNG
- **Uso**: Imagen de fondo en la página principal (home)

## Instrucciones

1. Colocá tus imágenes en esta carpeta
2. Avisame cuando las hayas agregado
3. Yo me encargo de integrarlas en el código

## Formatos aceptados
- PNG (recomendado para logo con transparencia)
- JPG/JPEG (recomendado para fotos/banners)
- SVG (recomendado para logo vectorial)
- WebP (opcional, mayor compresión)
